# 实验决策

## 会话按需使用，不替代独立进程

场景：读 JSON、触发 `KeyError`、取两个失败帧局部变量。两条路径核对出同一错误类型、记录编号和缺失字段。macOS arm64 / Python 3.11，每组两轮；总耗时包含冷启动和关闭。

| JSON 行数 | 会话：总耗时 | 每步独立进程：总耗时 | 文件读取次数 | 会话 / 独立进程反馈字节 |
| --- | --- | --- | --- | --- |
| 10,000 | 551–614 ms | 118–136 ms | 1 / 3 | 545 / 413 B |
| 350,000 | 650–675 ms | 386–395 ms | 1 / 3 | 546 / 414 B |
| 1,000,000 | 815–896 ms | 882–900 ms | 1 / 3 | 547 / 415 B |

独立进程的对照同样只输出紧凑证据，而不是完整日志。会话在这组对照里没有减少反馈字节；文件多读两次的成本接近冷启动时，才观察到总耗时接近或反超。这不证明真实 agent 的 token 节省、热会话性能或普遍的行数阈值。

## 隔离会话而非共享内核

共享内核会导致 agent 互相覆盖变量、失效的失败帧难以归因。每个会话单独启动；交接用代码版本、复现步骤和少量证据。跨会话只隔离 Python 状态，不隔离本机权限。
